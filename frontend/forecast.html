How the AI Works

The model is a Random Forest Regressor (scikit-learn) trained on historical Indian hospital admission data. It learns patterns from day-of-week, month, and public holiday flags to forecast admissions, ICU demand, and emergency load for the next 72 hours. Training takes ~2 seconds on any modern machine.

If the model file hea_model.pkl doesn't exist, the system falls back to a rule-based heuristic. Run python ml/train_model.py from the backend/ folder to enable full ML predictions.
